API Integration

Welcome to the Haxnation API documentation. Our seamless and secure API empowers developers to integrate certificate generation and event discovery natively into their own platforms. Using an approved B2B Community account, you can instantly render high-quality, verifiable certificates based on custom templates.

Base URLs

All API requests should be made to the following base URLs based on the resource type:

Admin / B2B Endpoints
https://api.haxnation.com/api/v1
Events Endpoints
https://api.haxnation.com/events/api/events

Authentication

ALL ENDPOINTS REQUIRE AUTHENTICATION VIA API KEY

The Haxnation API utilizes API Keys for authorization. While internal platforms use session cookies, any third-party domain or backend service calling any of our endpoints (including Events endpoints) MUST provide an API Key.

Key Types

  • PUBLIC Designed for client-side web applications. Strictly read-only and cannot generate certificates. Requires Allowed Domains whitelist to prevent unauthorized cross-origin requests.
  • PRIVATE Designed for backend-to-backend communication. Full access including certificate generation and credit deduction. Keep these keys strictly confidential.

Making Authenticated Requests

Pass your API key via the X-API-KEY HTTP header on all incoming requests:

X-API-KEY: HAX_abcdef1234567890abcdef... Content-Type: application/json

Generate Certificate

Dynamically generates a custom certificate based on the active template configured for your Community account. This endpoint consumes 1 credit per successful generation. Requires a PRIVATE key.

POST /api/v1/certificates/generate

Request Body

The payload must be a JSON object containing a data property. The keys inside data should exactly match the variable placeholders defined in your certificate template.

Field Type Description
data REQ Object Key-value mapping of template variable keys to their respective dynamic values.

Example Request

{ "data": { "name": "Jane Doe", "course": "Advanced AI Integration", "date": "October 24, 2026" } }

Responses

200 OK - Success
{ "success": true, "data": { "dataUrl": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAB..." } }
402 Payment Required - Insufficient Credits
{ "success": false, "message": "Insufficient credits" }

List Events

Retrieves a list of events available on Haxnation.

GET /events/api/events/

Response

200 OK - Success
{ "success": true, "data": [ { "id": "12345", "title": "CyberSecurity Summit 2026", "status": "ACTIVE", "location": "Virtual" } ] }

Get Event Details

Retrieves detailed metadata for a specific event by its ID or slug.

GET /events/api/events/{id}

Path Parameters

Parameter Type Description
id REQ String The unique ID or slug of the event.

Response

200 OK - Success
{ "success": true, "data": { "id": "12345", "title": "CyberSecurity Summit 2026", "description": "Annual security summit and CTF competition.", "settings": { "isCertificateOnly": false } } }

Verify Certificate

Endpoint to verify the authenticity of a certificate issued by Haxnation.

GET /events/api/events/certificate/verify/{certId}

Path Parameters

Parameter Type Description
certId REQ String The unique certificate identification hash to verify.

Response

200 OK - Success
{ "success": true, "data": { "message": "Certificate Verified", "owner": "Jane Doe", "event": "CyberSecurity Summit 2026", "isOwner": false, "eventId": "12345" } }
