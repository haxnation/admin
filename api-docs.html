Haxnation API Integration

Welcome to the Haxnation API documentation. Our seamless and secure API empowers developers to integrate certificate generation and event discovery natively into their own platforms. Using an approved B2B Community account, you can instantly render high-quality, verifiable certificates based on custom templates.

Base URL

All API requests should be made to the following base URLs based on the resource type.

Admin/B2B Endpoints 
https://api.haxnation.com/public/v1
Public Event Endpoints 
https://api.haxnation.com/api/events

Authentication

The Haxnation API utilizes API Keys for authorization. While internal platforms use session cookies, any third-party domain calling any of our endpoints (including Public Event endpoints) MUST provide an API Key.

Making Authenticated Requests

You must pass your API key via the X-API-KEY HTTP header in all requests made from external domains.

Headers 
X-API-KEY: HAX_abcdef1234567890abcdef...
Content-Type: application/json

Generate Certificate

Dynamically generates a custom certificate based on the active template configured for the API Client. This endpoint consumes 1 credit per successful generation.

POST /public/v1/certificates/generate

Request Body

The payload must be a JSON object containing a data property. The keys inside data should exactly match the variable placeholders defined in your certificate template.

Field Type Description
data Required Object A key-value mapping of the template variables to their respective dynamic values.
Example Request 
{
  "data": {
    "Name": "Jane Doe",
    "Course": "Advanced AI Integration",
    "Date": "October 24, 2026"
  }
}

Responses

The endpoint returns a JSON payload containing the generated certificate as a Base64 data URL upon success.

200 OK - Success 
{
  "success": true,
  "data": {
    "dataUrl": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAB..."
  }
}
402 Payment Required - Insufficient Credits 
{
  "success": false,
  "message": "Insufficient credits"
}

List Events

Retrieves a list of public events available on Haxnation. You can filter the events by a specific community ID.

GET /api/events/

Query Parameters

Parameter Type Description
communityId Optional String Filter the event list to show only events belonging to this specific community.

Response

200 OK - Success 
{
  "success": true,
  "data": [
    {
      "id": "12345",
      "title": "Summer Hackathon 2026",
      "status": "PUBLISHED",
      "location": "Virtual"
    }
  ]
}

Get Event Details

Retrieves detailed metadata for a specific event by its ID or slug.

GET /api/events/{id}

Path Parameters

Parameter Type Description
id Required String The unique ID or slug of the event.

Response

200 OK - Success 
{
  "success": true,
  "data": {
    "id": "12345",
    "title": "Summer Hackathon 2026",
    "description": "Join us for an amazing hackathon...",
    "settings": {
      "isCertificateOnly": false
    }
  }
}

Verify Certificate

Public endpoint to verify the authenticity of a certificate issued by Haxnation. You can embed this functionality into your own application to let users check if a certificate is valid.

GET /api/events/certificate/verify/{certId}

Path Parameters

Parameter Type Description
certId Required String The unique certificate ID to verify.

Response

Returns the certificate metadata along with verification status.

200 OK - Success 
{
  "success": true,
  "data": {
    "message": "Certificate Verified",
    "owner": "Jane Doe",
    "event": "Summer Hackathon 2026",
    "isOwner": false,
    "eventId": "12345"
  }
}
